# Historical personas

These six Soul Spec packages (Chronicler, Circle, Coder, Inference, Infra,
Pipeline) are the snapshot-era agent personas. They were retired or re-scoped
in the private system during the fall 2026 roster re-scope described in
`docs/what-changed-since-2026-08.md`.

They are kept here, unmodified apart from this move, because the snapshot-era
code in `packages/` references this roster and the design history is part of
what this public edition exists to show. Do not read them as current agent
definitions. The current top-level packages are `souls/aria/` and
`souls/insight/`.
